1. 表現できなかったこと: ExpressRoute 回線の途中にある機器が不明、という情報は書けません。経路や中間ノードが省略されていることは、形式上は不明として扱います。
2. 推測・追加したこと: `type` の値（router/switch/printer/gateway）、本社・大阪支店の group ID、接続 ID とラベルを補いました。広域イーサネットのリンク速度には契約帯域の `300M` を記しました。`cable: Ethernet` は「両端とも Ethernet」という記述をケーブル種別として表した推測です。ExpressRoute のリンクは中間機器やポートが不明なので、端点だけ記しました。
3. 不明確だったこと: 広域イーサネットの契約帯域 `300M` を `speed` に入れると、両端の引き渡し速度 `1G` と区別できません。また、LAG は複数リンクをまとめた接続として表せますが、その接続自体の帯域を別途記す欄はありません。
