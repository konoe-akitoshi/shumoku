1. The monitoring system recorded the switch’s model but not its maker. The format’s `product` path is described as running from maker to product, but does not specify how to represent a known model with an unknown maker. I used `/SWX2322P-16MT` to preserve the model.
2. I inferred the node types “switch,” “access point,” and “router” from the descriptions. I also represented the known Aruba and Yamaha products as `aruba` and `yamaha/rtx1300`.
3. The format does not say whether a `product` path may begin with `/` when the maker is unknown.
