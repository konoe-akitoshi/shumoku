# 機材の登録

Materials では製品ライブラリと必要数量を管理します。

- カタログから製品を選び、**Add to Library** で登録します。
- カスタム製品は仕様を入力して **Create Product** で作成します。
- 必要数量を追加するときは **Add to Required** を使います。
- 製品の詳細画面で仕様やアイコンを確認・編集できます。
- Scene に配置するときは、[Place item の Products](../pages/scene.md) から登録済み製品を選びます。

必要数量と配置済み数量は別の値です。必要数量を変更することと、図上の機器を追加・削除することを区別してください。
必要部材の確認は [BOM](./bom.md)、保存は [Settings](../pages/projects.md) で行います。
