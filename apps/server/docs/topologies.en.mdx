## Creating a Topology

1. Navigate to **Topologies** in the sidebar
2. Click **Add Topology**
3. Enter a name and save
4. On the **Sources** screen that opens, add a Manual source or a plugin data source

## Writing It by Hand

In a Manual source's editor, write the configuration as YAML. The YAML holds the configuration only (nodes, links, groups, segments, ...). Identity found by plugins and the drawing's positions and colours are not shown in it and are kept as they are.

```yaml
name: My Network
groups:
  - id: dc
    label: DC
nodes:
  - id: router1
    label: Core Router
    type: router
    product: juniper/mx204
    group: dc
  - id: switch1
    label: Distribution Switch
    type: l2-switch
    group: dc
links:
  - endpoints: [{ node: router1, port: ge-0/0/0 }, { node: switch1, port: ge-0/0/1 }]
    speed: 10G
```

- A link lists its two ends in `endpoints`. Leave out a port that is not known.
- Write a speed with its unit, such as `1G`, `10G` or `2.5G`.
- Groups are written nested under `groups`; a node names its group with `group`.
- Anything not written is unknown, not absent.

The older format (`from` / `to`, `subgraphs`, files split with `file:`) is not read; rewrite it.

## How the diagram is drawn

There is nowhere to write coordinates or which way is up. Up and down come from the input. Neither the YAML nor the UI has a field that names where they are measured from (the boundary).

- The boundary (where the network meets what lies beyond it) is decided in this order; an earlier step wins and the later ones are not used.
  1. The drawing setting `boundary` (`drawing.settings.boundary`). The YAML and the UI cannot set it; it is used only when a program puts it in the drawing layer of a `NetworkModel`.
  2. `type: external` and `type: cloud` nodes, and the routing domains that links reach. `type: internet` is not included.
  3. When step 2 finds none, nodes that have both a cable and a virtual link (`virtual: true`).
  4. For each connected part that none of 1-3 reaches, a guessed upstream: by type (router, firewall, VPN and CPE, then L3 switch and load balancer, then L2 switch, then access point), then the node(s) ending the fastest link, and failing those the most central node. The guess is made per part, also when other parts have a boundary. A lone node gets nothing.
  The guess is plain. When up and down matter, write what lies beyond the network (the Internet, an ISP, a cloud) as `type: external` or `type: cloud` nodes linked to the inside. From NetBox, circuits and providers come in as `external` nodes.
- Lines are drawn as right-angle and 45-degree segments, with corners rounded by arcs. Arrows, splines and double lines are gone. A virtual link is dashed and an assumed one dotted; the line's width follows `speed`. A line carrying a single VLAN is drawn in that VLAN's colour (taken in VLAN-id order, distinct within one diagram, each at least 3:1 against the background; a diagram with more such VLANs than can be told apart, 7 in the light theme and 9 in the dark, colours none); a line carrying several VLANs (a trunk) or none is drawn in the plain line colour, and its caption lists what it carries.
- Nested groups are drawn as frames on one page. Splitting a group into its own sheet (`file:` / `pins`) is gone.
- **Settings** > **Display** keeps one switch, **Hide Disconnected Nodes**, which hides every node with no links after the sources are merged, with no exemption. Only the Server applies it. The edge style and spline settings are gone.

## Linking Data Sources

In the topology **Settings** tab:

1. Add a **Metrics Source** (Zabbix or Prometheus) for real-time link utilization and node status
2. Add a **Topology Source** (NetBox) to auto-generate or merge topology data
3. Configure **Node Mapping** to associate topology nodes with monitored hosts

## Sharing

Click the **Share** button on any topology to generate a public link. Anyone with the link can view the topology without logging in.

To revoke access, delete the share token in the topology settings.

## Exporting

Use **Export** in the topology viewer to download the whole diagram as SVG or a
2x PNG, or as a standalone interactive HTML document. Server exports use the same
drawing engine and renderer as the viewer and CLI. Hierarchical sheets are gone:
nested groups are drawn together on one page.
