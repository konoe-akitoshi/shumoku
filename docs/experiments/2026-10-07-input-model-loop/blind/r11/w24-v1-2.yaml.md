1. The description does not say which ports the ONU-to-router fiber or the power cables use; I left those unspecified. Outlet numbers are recorded as descriptions because the format has no outlet field.
2. I added branch and headquarters groups to represent the stated locations, and used “IPsec tunnel” as the tunnel link’s description.
3. The format does not specify whether a link from a PDU to a device should identify the device’s power inlet as a port. It also does not define a dedicated field for outlet numbers.
