1. **表現できなかったこと:** ExpressRoute の途中にある機器が不明であることは、リンクの途中経路として直接表せません。
2. **推測・補足したこと:** ノードの `type`、拠点のグループ分け、接続の ID とラベルを補いました。広域イーサネットの `speed: 300M` は契約帯域として記しましたが、両端の引き渡し Ethernet が 1G であることと、リンクのケーブル種別としての Ethernet は区別して表せません。IPsec トンネルは `virtual: true` としました。
3. **不明確だったこと:** `speed` が物理ポートの対応速度、実際のリンク速度、契約帯域のどれを表すかが明確でありません。また、ExpressRoute 回線の 2G がリンク速度なのか契約帯域なのかも判別できません。
