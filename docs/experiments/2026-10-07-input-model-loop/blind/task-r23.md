# 課題

本社と大阪支店のネットワーク。

- 本社のルータ rt-1 の te1 とコアスイッチ sw-1 の te0/1 が 10G でつながっている。
- sw-1 と sw-2 は、te0/47 どうし・te0/48 どうしの 10G 2本を束ねた LAG でつながっている。
- sw-2 の ge0/10 にプリンタ prn-1 がつながっている。ポートは 1G 対応だが、リンクは 100M で上がっている。
- rt-1 の ge0 は通信事業者の広域イーサネットを通って、大阪支店のルータ rt-2 の ge0 と結ばれている。
  引き渡しは両端とも 1G の Ethernet で、回線の契約帯域は 300M。
- rt-1 から Azure の ExpressRoute ゲートウェイ ergw へ、ExpressRoute の回線（帯域 2G）がある。途中の機器は分からない。
- rt-2 から rt-1 へ、バックアップの IPsec トンネルが張られている。
