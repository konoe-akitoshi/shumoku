**Confusing points**

- The format says a node can belong to a segment without a known link, while a link to a segment also places the node in it. So a link from `tgw-1` to `sub-c` does not, by itself, say `tgw-1` is in `sub-c`.
- The format allows unlisted links and partial address lists, so missing link or address entries do not establish absence.
- `app-1`'s `host: prod` identifies a redundancy set, not a specific host.
