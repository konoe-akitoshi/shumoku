1. ExpressRoute の回線帯域 2G は書けますが、途中の機器や経路は不明なので表現できません。
2. `type` の値は自由記述なので、router、switch、printer、expressroute-gateway と補いました。LAG、広域イーサネット、ExpressRoute、IPsec は `connection` として表しました。プリンタのポートが 1G 対応であることは、形式にポート能力の項目がないため記載していません。
3. `bandwidth` は `Rate` 型のため、`2G` を書けるものとして扱いました。`speed` は列挙された Ethernet 速度に限られるため、ExpressRoute 回線には指定していません。
