書いてあることは落とさないでください。

- 本社のサーバ室に、ルータ rt-1（Yamaha RTX3510）とスイッチ sw-1（型番は「SWX2322P-16MT」と記録されて
  いるが、メーカーは記録されていない）がある。
- rt-1 の lan3 と sw-1 の port 1 は、3m の Cat6 で 1G。VLAN 10（業務、192.168.10.0/24）と VLAN 20
  （来客）を運ぶ。VLAN 20 は rt-1 の VRF「guest」に属する。
- 仮想化ホスト hv-1（Dell PowerEdge R750、VMware ESXi）が sw-1 に 10G でつながる（ポート不明）。VM の
  web-1 が hv-1 上で動き、アダプタは VLAN 10 のポートグループにあって、アドレスは 192.168.10.20。
- rt-1 と sw-1 の電源は PDU pdu-1 のコンセント 1 と 2 から。
- AWS 東京の VPC「main」（10.0.0.0/16）に、サブネット sub-a（10.0.1.0/24、ap-northeast-1a）がある。
  インターネットゲートウェイ igw-1 が VPC に付いている。rt-1 から VPC の仮想プライベートゲートウェイ vgw-1
  へ IPsec の Site-to-Site VPN があり、トンネルは2本。
