```yaml
name: 本社ネットワーク

groups:
  - id: headquarters
    label: 本社
  - id: server-room
    label: サーバ室
    parent: headquarters

routingDomains:
  - id: guest
    label: guest

segments:
  - id: vlan-10
    label: 業務
    vlan: 10
    prefix: 192.168.10.0/24
  - id: vlan-20
    label: 来客
    vlan: 20
    routingDomain: guest
  - id: aws-vpc-main
    label: AWS 東京 VPC main
    prefix: 10.0.0.0/16
  - id: sub-a
    label: sub-a
    prefix: 10.0.1.0/24
    group: aws-vpc-main

nodes:
  - id: rt-1
    label: rt-1
    type: router
    product: Yamaha RTX3510
    group: server-room
  - id: sw-1
    label: sw-1
    type: switch
    product: SWX2322P-16MT
    group: server-room
  - id: hv-1
    label: hv-1
    type: virtualization host
    product: Dell PowerEdge R750
    software: VMware ESXi
    group: server-room
  - id: web-1
    label: web-1
    type: VM
    host: hv-1
    address: 192.168.10.20
  - id: igw-1
    label: igw-1
    type: internet gateway
    group: aws-vpc-main
  - id: vgw-1
    label: vgw-1
    type: virtual private gateway
    group: aws-vpc-main

connections:
  - id: site-to-site-vpn
    label: IPsec Site-to-Site VPN

redundancy:
  - id: vpn-tunnels
    label: VPN トンネル
    nodes: [rt-1, vgw-1]

links:
  - endpoints:
      - node: rt-1
        port: lan3
      - node: sw-1
        port: "1"
    speed: 1G
    cable: Cat6
    length: 3m
    segments: [vlan-10, vlan-20]
  - endpoints:
      - node: sw-1
      - node: hv-1
    speed: 10G
    segments: [vlan-10]
  - endpoints:
      - node: igw-1
      - node: vgw-1
    segments: [aws-vpc-main, sub-a]
  - endpoints:
      - node: rt-1
      - node: vgw-1
    connection: site-to-site-vpn
    assumed: true
```

1. **表現できなかったこと:** AWS のリージョン（東京、`ap-northeast-1`）、サブネットのアベイラビリティゾーン（`ap-northeast-1a`）、VPN のトンネル数が2本であること。型にはリージョン、AZ、トンネル数を記録する項目がありません。web-1 のアダプタが VLAN 10 のポートグループにあることも、VM のアダプタやポートグループを表す型がありません。
2. **補ったこと:** 本社とサーバ室を groups にしました。VPC とサブネットは segments として表し、サブネットを VPC の子にしました。型には VPC や subnet 固有の構造がないため、この対応付けは推測です。IGW と VGW の VPC への所属も group で表しました。VPN を connection として記録し、VPN のリンクには `assumed: true` を付けました。VLAN 10 がホスト接続にも関係すると解釈して、sw-1–hv-1 のリンクに含めました。
3. **形式で迷った点:** `redundancy` が VPN トンネル2本を表せるか不明です。nodes のみを指定でき、トンネル数やリンクとの対応を直接記録できないため、VPNトンネルの冗長性として置きました。`Segment.addresses` のキーの意味も型だけでは分からず、今回は使いませんでした。
