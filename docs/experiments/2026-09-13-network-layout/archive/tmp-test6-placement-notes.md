# 配置のみの共同最適化実験

実行:

```powershell
bun run tmp-test6-placement-experiment.mjs
bun run tmp-test6-export-placement.mjs
```

入力は `tmp-test6-complete-upstream-to-ap.json`（89ノード、160リンク）。
本番エンジンとは独立した実験。入力ファイルを変更しない。

役割を配置から除外する比較実験:

```powershell
bun run tmp-test6-placement-experiment.mjs --role-free
bun run tmp-test6-export-placement.mjs --role-free
```

このモードの出力は `tmp-test6-role-free-placement*`。
ノードの役割・リンクの役割・帯域・入力のfrom/to方向を配置判断に使わない。
外部境界は利用者が指定するものとして `test:internet` を明示的にアンカーにする。
無向・無重みグラフの最短ホップ距離だけから弱い下向き選好を作る。
同ホップ接続には上下の選好を付けない。隣接ノード数で引力を正規化する。
グループは明示されたparentを継承し、極座標で初期化する。固定tier行は使わない。
機器・リンクの役割による色とテキストは比較用の表示にのみ残す。
fallbackなどの横断接続も最短経路に含まれるため、ホップ距離は物理的な上下流を保証しない。
この比較は役割情報に加えて初期化と距離重みも変わるため、単独要因の効果測定ではない。

全ノードのxy座標と全表示グループの中心・半幅・半高さが変数。
同一の評価関数に対して対角スケーリング付き勾配降下とバックトラックを行う。
初期配置5種類から実行し、検査違反数、その後コストの順で選択する。
初期化には役割順の行を使うが、更新中に行・順序・境界を固定しない。

評価項目:

- 関係別の距離範囲と下流の角度範囲
- 推測した役割に基づく上下関係（弱い）と、追加した上下流接続（強い）
- ノード矩形の非重複、グループ包含、グループ矩形の非重複
- グループの広さとまとまり
- フロア間peerとHAリンクの弱い高さ合わせ
- 役割レベルへの弱い高さの誘導、全体の横広がり、Internet位置の基準

配置上は同じ両端のリンクを1関係に数える。図は元の全160リンクを直線として描く。
同じ端点の並列リンクは重なって見える。オレンジ破線はfloor-peer、fallbackは薄い線。
配線経路、交差数、帯域線幅、ポート配置・ポートラベルは最適化に含めない。
ノード図形は実験用の名前付き矩形で、本番SVGレンダラーのサイズではない。

有限ペナルティ方式のため任意入力に対する必須制約の保証はない。
選択結果の検証値を `tmp-test6-joint-placement-report.json` に保存する。
上下流検査は、追加リンクの向きに対する85pxの中心間隔を1px許容で検査する。
包含検査は矩形の実体を0.5px許容で検査する。
単純な非重複に加え、評価関数ではノード18px、グループ26pxの余白を要求する。
計算式と勾配は全変数の有限差分で照合する。

役割・peer・HAの元アノテーションには以前の補完時の推測が含まれる。
履歴からの配置安定性、明示的な固定位置、入れ子・交差する所属、
HAペアを一体の単位にする処理、厳密な制約充足ソルバーは未実装。
既存の段状初期配置や局所解への依存も、今後の比較対象とする。

リポジトリのBiome設定はインストール済みCLIが解釈できない `preset` を含む。
実験ファイルは独立設定でチェック:

```powershell
bun x biome check --config-path=tmp-test6-biome.json tmp-test6-placement-experiment.mjs tmp-test6-export-placement.mjs
```
