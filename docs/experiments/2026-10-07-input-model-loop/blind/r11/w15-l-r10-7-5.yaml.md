2. **Guesses or additions:** I represented the VPC attachment to each subnet and the instance/database adapter attachments as virtual links. The two identical VPN links represent the two tunnels; the format has no tunnel identifier or IPsec-specific field. I used conventional product paths and node types, and associated the internet gateway with sub-a because the format has no direct VPC attachment endpoint and the description does not name a subnet for the gateway. I left the VLAN 20 address on ap-1 in the segment’s address map.
