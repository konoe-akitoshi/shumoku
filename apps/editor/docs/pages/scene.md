# Map ページ

Map は、任意の図面画像に機器・端子を配置して配線経路を編集する画面です。
[Diagram](./diagram.md) と同じ機器・接続を使います。サブグラフやフロアの単位とは独立し、
1枚に複数フロアを含む画像も、フロアごとに分かれた画像も並べて扱えます。
旧 Scene の画面URLは Map に転送されます。

## 図面の準備

1. 画面下部の **Map** に切り替え、**Edit mode** を押します。
2. **Add images** から図面画像を追加します。複数画像を選択できます。
3. 画像をクリックして **Set scale** を押し、実距離が分かる二点を指定します。
   メートル単位の距離を入力して **Apply scale** で確定します。Esc で中止できます。
4. **Unplaced** から既存機器を選び **Place**、または **New device**、**Outlet**、
   **EPS**、**Panel** を選び、図面上をクリックして配置します。

画像ごとに縮尺を設定すると、同じ実寸基準に揃います。1枚の中に異なる縮尺の図がある場合は、
画像を分割して登録してください。画像の移動・縮尺変更には紐付いた機器や配線の折れ点が追従します。
**Lock** / **Unlock** で画像移動を固定・解除できます。
**Remove image** は背景のみを外し、機器と接続は残します。

## 配線と省略

機器のハンドル同士を接続すると、Diagram と共通の接続が作成されます。
線をドラッグすると区間を移動し、Alt を押しながらドラッグすると折れ点を追加します。
操作中の Esc は変更を取り消します。

線を選択して **Omit span** を押すと、途中を省略して `C1 · A` / `C1 · B` のような対を表示します。
接続データは1本のままで、端点は自由に移動できます。端点を選んで **Go to other end** で
相手側へ移動、**Restore line** で省略を解除します。
省略端点に隣接する区間を編集するときは、一度省略を解除してください。

**Omitted length** に省略区間の実長を入力します。空欄は不明、0は長さゼロを意味します。
図面間のキャンバスの空白は配線長に算入しません。通常区間も、両端が同じ校正済み画像に
紐付いた場合のみ測定でき、全区間が分かるまで計算による全長は未確定です。

機器をマップから削除しても、Diagram の機器・接続は残ります。再配置は **Unplaced** を使います。

## 保存と旧データ

プロジェクトZIPには画像・縮尺・配置・省略設定を保存します。
JSON/SVG出力は構成図の出力です。マップの印刷は **Print** を使います。

旧Sceneは1つのMapに移行され、同じ機器の配置は1か所に統合されます。
元の配置は **Imported placements** から選び直せます。所属図面が曖昧な折れ点・端子は
位置を確認して置き直してください。移行前のファイルは保管し、移行後のファイルを旧Editorで
上書き保存しないでください。

設計上の制約と参考資料は [map-workspace.md](../design/map-workspace.md) を参照してください。
