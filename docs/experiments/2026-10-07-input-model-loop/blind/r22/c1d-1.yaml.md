1. **表現できなかったこと:** VM アダプタが VLAN 10 のポートグループにあることは、web-1 と VLAN 10 の仮想リンクとして表しましたが、「ポートグループ」という名前やアダプタの詳細は表現できませんでした。サブネットの availability zone は group として表しました。
2. **補ったこと・推測したこと:** 本社、サーバ室、AWS 東京、AZ をグループとして整理し、AWS 東京の具体的な AZ は `ap-northeast-1a` としました。VPC を routing domain、サブネットを segment、IGW/VGW と各機器の type に記述された種類を割り当てました。VPN の2本のトンネルを同じ connection に属する仮想リンクとして表しました。ポート不明は `port unknown` と記しました。
3. **形式で迷った点:** group が「場所」向けなので AZ を group にしてよいか、また AWS 東京を独立した group として書くべきか迷いました。VPC は routing domain としましたが、説明上の VPC と形式の routing domain が完全に同じ概念かは明示されていません。リンクに ID がないため、2本のトンネルは description で区別しました。
