2. **Guessed or added:** I used generic `type` values and product paths where the description did not specify a canonical vocabulary. I modeled the AWS availability zones as groups and used virtual links for the VM adapters and VPN tunnels. The link format has no identifier, so the two tunnel links are indistinguishable.
3. **Unclear:** A routing-domain endpoint is described as a node attached to the domain as a whole. It is unclear whether it can also represent an internet gateway’s attachment to a VPC.
