2. I guessed generic `type` values for devices and cloud resources, product paths, and some group placements for AWS resources. I treated “rt-1 has a Site-to-Site VPN connection” as two links from rt-1 to tgw-1 and marked them assumed because the description identifies the VPN but does not explicitly confirm each tunnel’s existence. I left the unspecified server ports out.
3. `virtual` appears to fit the VM adapters, IGW/TGW attachments, and VPN tunnels because they have no cable of their own. It is unclear whether an endpoint-to-routing-instance link fully captures an attachment, or how to model a resource such as an IGW that is attached to a VPC but has no stated address or interface.
