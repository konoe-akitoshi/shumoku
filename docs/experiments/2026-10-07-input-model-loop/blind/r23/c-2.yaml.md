1. ExpressRoute の途中にある機器や経路は不明なので表現していません。
2. ノードの `type`、各拠点への所属、`ergw` が本社側にあることは補いました。広域イーサネットのリンク速度には契約帯域の 300M を記し、1G の引き渡し速度は `speed` に併記できないため、`cable: Ethernet` で表しました。
3. `speed` がリンクの実速度・ポート速度・契約帯域のどれを表すかは型だけでは明確でありません。また、LAG が複数リンクを束ねる論理接続として `connection` で表せるか、`assumed` が「途中が不明」な ExpressRoute に適用できるかも不明です。
