1. **表現できなかったこと:** ExpressRoute の途中の機器が不明であることは、リンクの説明などに書けますが、この形式には「途中経路が不明」を直接表す項目がありません。
2. **推測・追加したこと:** ノードの `type`、支店と本社の配置、Azure を routing domain としたこと、各接続の ID とラベルを補いました。プリンタの対応速度はリンクの実速度とは別に表せないため、`bandwidth: 100M` にも設定しました。広域イーサネットの 1G は引き渡しの速度としてリンクの `speed` に置きました。
3. **不明確だったこと:** `speed` がポートの対応速度とリンクの実速度のどちらを指すか、また `bandwidth` が契約帯域以外の用途にも使えるかが不明です。ExpressRoute の 2G も、帯域として `bandwidth` に記しました。 `virtual` は物理ケーブルがない接続を示すと解釈しました。
