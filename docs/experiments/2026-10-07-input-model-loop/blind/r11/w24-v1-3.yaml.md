```yaml
name: Small branch
groups:
  - id: headquarters
    label: Headquarters

nodes:
  - id: onu
    label: ONU
    type: ONU
  - id: rt-1
    label: Router
    type: router
    icon: https://example.com/rt.svg
  - id: sw-1
    label: Switch
    type: switch
  - id: srv-1
    label: Server
    type: server
  - id: hq-rt
    label: Headquarters router
    type: router
    group: headquarters
  - id: pdu-1
    label: PDU
    type: PDU

links:
  - endpoints:
      - node: onu
      - node: rt-1
        port: lan2
    cable: fiber
    length: 2m
  - endpoints:
      - node: rt-1
        port: lan3
      - node: sw-1
        port: xe-0/2/3
    speed: 10G
    segments: [vlan10, vlan20]
  - endpoints:
      - node: sw-1
        port: ge-0/0/1
      - node: srv-1
    speed: 1G
    segments: [vlan10]
  - endpoints:
      - node: rt-1
      - node: hq-rt
    virtual: true
    description: IPsec tunnel
  - endpoints:
      - node: rt-1
      - node: pdu-1
        port: "1"
    cable: power
  - endpoints:
      - node: sw-1
      - node: pdu-1
        port: "2"
    cable: power
  - endpoints:
      - node: srv-1
      - node: pdu-1
        port: "3"
    cable: power

segments:
  - id: vlan10
    label: office
    vlan: 10
  - id: vlan20
    label: voice
    vlan: 20

view:
  - match:
      cable: power
    stroke: gray
  - match:
      segment: vlan10
    stroke: blue
  - match:
      between: [onu, rt-1]
    stroke: magenta
  - match:
      virtual: true
    dashed: true
  - match:
      node: rt-1
    icon: https://example.com/rt.svg
```

1. The outlet numbers are recorded as PDU endpoint ports. The format has no dedicated outlet field.
2. I inferred the names `vlan10` and `vlan20`, the headquarters group ID, and labels/types for devices where the description gave a role but no exact label or type vocabulary. I treated the IPsec tunnel as virtual and used `fiber` for the ONU cable type.
3. `ViewRule.match.between` names a link by its two nodes, but the format does not say how it distinguishes parallel links between the same nodes. Also, a rule matching `segment: vlan10` styles every link carrying VLAN 10, so the later ONU-to-router rule overrides blue if that link also matches VLAN 10; it does not here.
