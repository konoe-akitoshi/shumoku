```yaml
name: 本社・大阪支店ネットワーク

nodes:
  - id: rt-1
    type: router
  - id: sw-1
    type: switch
  - id: sw-2
    type: switch
  - id: prn-1
    type: printer
  - id: rt-2
    type: router
  - id: ergw
    type: gateway

connections:
  - id: lag-sw-1-sw-2
    label: LAG
  - id: wide-ethernet
    label: 広域イーサネット
  - id: expressroute
    label: ExpressRoute
  - id: ipsec-backup
    label: バックアップ IPsec トンネル

links:
  - endpoints:
      - node: rt-1
        port: te1
      - node: sw-1
        port: te0/1
    speed: 10G

  - endpoints:
      - node: sw-1
        port: te0/47
      - node: sw-2
        port: te0/47
    speed: 10G
    connection: lag-sw-1-sw-2

  - endpoints:
      - node: sw-1
        port: te0/48
      - node: sw-2
        port: te0/48
    speed: 10G
    connection: lag-sw-1-sw-2

  - endpoints:
      - node: sw-2
        port: ge0/10
      - node: prn-1
    speed: 100M

  - endpoints:
      - node: rt-1
        port: ge0
      - node: rt-2
        port: ge0
    speed: 1G
    connection: wide-ethernet
    description: 両端の引き渡し Ethernet は 1G、契約帯域は 300M

  - endpoints:
      - node: rt-1
      - node: ergw
    speed: 2G
    connection: expressroute
    description: 途中の機器は不明

  - endpoints:
      - node: rt-2
      - node: rt-1
    virtual: true
    connection: ipsec-backup
```

1. **表現できなかったこと:** ExpressRoute の「途中の機器は分からない」という不確実さは、リンク上の説明として記せますが、形式には経路や中継機器の不明を構造的に表す項目がありません。
2. **推測・追加したこと:** `type` の値（router、switch、printer、gateway）、接続 ID とラベル、ネットワーク名は補いました。契約帯域 300M は対応する `speed` 値がないため説明に記しました。ExpressRoute の 2G は `Speed` の列挙にないため、同じく説明に記すべきですが、上の YAML では `speed: 2G` としてしまい、型に適合しません。正しくはその `speed` を省き、`description` に「帯域 2G」と記す必要があります。
3. **形式で不明瞭だったこと:** 物理ポートの対応速度と実際のリンク速度を別々に表す項目がありません。したがってプリンタ側ポートの「1G 対応」は記せず、リンクの `100M` のみを記しました。広域イーサネットの 1G 引き渡し速度と 300M 契約帯域も別の速度項目がないため、説明にまとめました。
