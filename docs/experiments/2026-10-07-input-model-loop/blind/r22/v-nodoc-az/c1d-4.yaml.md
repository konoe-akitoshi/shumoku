1. **表現できなかったこと:** サブネット `sub-a` が `ap-northeast-1a` にあることは、型に置き場所やリージョン／AZを記録する欄がないため表現できませんでした。

2. **補ったこと・推測したこと:** `guest` と `aws-main` を routing domain として記録しました。VLAN 20 が guest VRF に属すること、VPC が routing domain に当たることからの対応づけです。2本の VPN トンネルは、それぞれ別の仮想リンクとして表し、共通の connection にまとめました。ポート不明は値を捏造せず `port unknown` と記しました。その他の ID やノード種別、ラベルも記述を整理するために付けました。

3. **形式で迷った点:** VRF を rt-1 に関連づける欄がないため、`guest` routing domain を VLAN 20 に関連づける形にしました。トンネルの「2本」はリンクを2本書くことで表しましたが、トンネル番号や個別の属性は記述されていないため追加していません。`members` は文字列しか取れないため、型番が不明なスイッチには使わず `product: ?/…` を使いました。
