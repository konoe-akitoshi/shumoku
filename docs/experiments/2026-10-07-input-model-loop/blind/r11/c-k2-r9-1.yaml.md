1. The cluster’s behavior—VMs restart on another host after a host failure—has no field in the format.
2. I used `Server room` as the network name and added node types, software/product classification, and the server-room group for the physical equipment. The format does not define standard values for `type` or `product`. I represented each VM adapter as a one-ended virtual link to its segment; this records its segment attachment but leaves the host-side port group implicit.
3. It is unclear whether a one-ended link is valid, since the type requires exactly two endpoints. The format also does not say how to represent a VM’s adapter in a port group beyond marking a link virtual and associating it with a segment.
