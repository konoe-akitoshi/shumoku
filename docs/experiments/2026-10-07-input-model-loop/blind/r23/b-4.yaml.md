1. **表現できなかったこと:** ExpressRoute 回線の途中に機器があること自体は表せません。記述上、機器や接続経路は不明です。
2. **推測・追加したこと:** ネットワーク名、ノードの表示名、各論理接続の ID とラベルを補いました。LAG の2本は同じ `connection` にまとめています。ExpressRoute の2Gは `speedMbps` に記しましたが、形式には物理リンク速度と回線帯域を区別する項目がありません。
3. **形式で不明確だったこと:** `speedMbps` がリンクの実速度、ポート能力、契約帯域のどれを表すか、また論理接続の帯域をどこに記すかが明確ではありません。IPsec トンネルのリンクに `virtual: true` を付けました。
