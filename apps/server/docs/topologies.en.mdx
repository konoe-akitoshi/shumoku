## Creating a Topology

1. Navigate to **Topologies** in the sidebar
2. Click **Add Topology**
3. Enter a name and save
4. On the **Sources** screen that opens, add a Manual source or a plugin data source

## Writing It by Hand

In a Manual source's editor, write the configuration as YAML. The YAML holds the configuration only (nodes, links, groups, segments, ...). Identity found by plugins and the drawing's positions and colours are not shown in it and are kept as they are.

```yaml
name: My Network
groups:
  - id: dc
    label: DC
nodes:
  - id: router1
    label: Core Router
    type: router
    product: juniper/mx204
    group: dc
  - id: switch1
    label: Distribution Switch
    type: l2-switch
    group: dc
links:
  - endpoints: [{ node: router1, port: ge-0/0/0 }, { node: switch1, port: ge-0/0/1 }]
    speed: 10G
```

- A link lists its two ends in `endpoints`. Leave out a port that is not known.
- Write a speed with its unit, such as `1G`, `10G` or `2.5G`.
- Groups are written nested under `groups`; a node names its group with `group`.
- Anything not written is unknown, not absent.

The older format (`from` / `to`, `subgraphs`, files split with `file:`) is not read; rewrite it.

## How the diagram is drawn

Up and down come from the input; there is nothing to write coordinates in.

- Write what lies beyond the network (the Internet, an ISP, a cloud) as a `type: external` or `type: cloud` node: it becomes the top tier and the rest is laid out below it. With no named boundary, nodes that have both a cable and a virtual link (`virtual: true`) count as the boundary. With neither, each connected part gets a guess at its upstream: by type (router and firewall, then L3 switch, L2 switch, access point), then by its fastest link, and failing those its most central node goes on top. It is a plain guess, so name the outside nodes when up and down matter.
- Lines are drawn at right angles and 45 degrees only. Arrows, splines and double lines are gone. A virtual link is dashed and an assumed one dotted; the line's width follows `speed`.
- Nested groups are drawn as frames on one page. Splitting a group into its own sheet (`file:` / `pins`) is gone.
- **Settings** > **Display** keeps one switch, **Hide Disconnected Nodes**. The edge style and spline settings are gone.

## Linking Data Sources

In the topology **Settings** tab:

1. Add a **Metrics Source** (Zabbix or Prometheus) for real-time link utilization and node status
2. Add a **Topology Source** (NetBox) to auto-generate or merge topology data
3. Configure **Node Mapping** to associate topology nodes with monitored hosts

## Sharing

Click the **Share** button on any topology to generate a public link. Anyone with the link can view the topology without logging in.

To revoke access, delete the share token in the topology settings.

## Exporting

Use **Export** in the topology viewer to download the whole diagram as SVG or a
2x PNG, or as a standalone interactive HTML document. Server exports use the same
drawing engine and renderer as the viewer and CLI. Hierarchical sheets are gone:
nested groups are drawn together on one page.
