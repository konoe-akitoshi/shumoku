I modeled the IX peering LAN as a segment within a routing domain, used placeholder node IDs for the unnamed AS routers, and represented the AS64520 peering with virtual links to the LAN plus a virtual link between the routers. The format does not have a specific eBGP-session link type, so I used `connection` to identify each session.
3. It is unclear whether an eBGP session over a known cable should be represented as the cable link itself, as a separate virtual link, or as a `connection` spanning links.
