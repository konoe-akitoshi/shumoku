**Confusing points**

- The format says a listed link’s segments are complete, but does not say whether a segment’s address list is complete.
- It says a node is in a segment if it has an address there or a link carrying the segment ends at it; it does not require the address and link information to match.
- The format does not state whether a routing domain can contain segments that omit `routingDomain`, or whether a segment can belong to multiple routing domains.
