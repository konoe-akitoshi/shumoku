# 部材表の確認

BOM は、登録した製品と図の機器・接続から必要部材をまとめる画面です。
表の内容を修正するときは、元となる Materials、Diagram、Connections の情報を変更します。

- 必要部材と数量を確認します。
- **Copy Table** で部材表をコピーします。**Open Materials** で機材の管理画面に戻れます。
- ケーブルの **Label CSV** は、両端のラベル印刷用データを出力します。
- 修正が必要な項目は、表示される移動ボタンから元の画面に戻って確認します。

部材表の出力はプロジェクトのバックアップではありません。
編集を再開できる形式の保存には [Settings の Export](../pages/projects.md) を使います。
