# 接続構造からの上流候補解析（2026-09-13）

最初は配置とは独立して検証し、厳密な共通極大の検出をV8 dependency-yに統合した。
その後、ユーザー合意により接続位置ごとの得票ランキングへ更新した。
「比較した仮説」以降は旧方式の解析記録であり、`report.json` も旧解析の結果。
`analyze.mjs` は役割、名称、座標、サブグラフを判定に使わない。

## 上流検出モジュール

`upstream.mjs` の `detectUpstream(graph)` は候補ID配列、成分ごとの端点・候補・得票、
未解決成分、全候補から同時に求めた最短距離を返す。
`dependencyUpstream(baseline)` は配置レポートのリンクインデックスを変換するアダプタ。
端点なし・次数2以上の候補なし・最高得票0の場合は「上流未定」の成分として返す。
依存距離は `null` のまま保持し、配置側で上下依存項だけを省く。
配線距離項と余白・重なり回避は継続する。未解決理由は `unresolved` に残る。
端点のない成分を自明な全員一致と解釈しない。
空の準備済みレイアウト、不正リンク、配置ソルバー失敗などは別問題であり、例外を隠さない。

端点の唯一の接続先ごとに1グループとし、その接続先からBFSを実行する。
候補は次数2以上に限定する。端点そのものを選ぶと他の端点からほぼ常に終着点に見えるため。
各グループから見て全隣接ノードが自分より近ければ1票とし、最高得票の候補をすべて残す。
同じ接続先のAPを増やしても票は増えない。成分ごとに集計する。
同点を破るID選択や合格率の閾値はない。score は votes / total で、確率ではない。
複数起点の距離0・同距離の関係を保持し、既存の内部依存スプリングは再計算した距離を使う。
座標の平行移動だけは候補のIDソート先頭をゲージとする既存機構を使う。
全成分が上流未定なら全ノードのID順先頭をゲージとする。これは根や距離0の補完ではない。
この区別と null の扱いを `upstream.mjs` と `layoutDependencyY` のコードコメントに記載した。
孤立ノード・2端点だけ・全候補0票の星形・端点なしのリング・既知/未知成分の混在を
実際に配置計算まで通す回帰テストを追加した。現段階は既存Xと配線構造を用いるY最適化である。
今回の入力ではInternetが9/9票で単独首位。Internet削除時はISP-A/Bと
nexus9164e-ns4.dcが各8/9票で同率首位となる。内部機器1台を含む近似であり、
ISPだけになるような例外処理は追加しない。木構造の上流が次数1の場合などは対象外。
判定の詳細はレポートの `upstream.components` の `sourceGroups` と `candidates` に保存する。
複数候補・非連結・端点なし・入力順反転・多重リンク・名前変更をテストする。
Internet の ID は比較用の削除シナリオにのみ使用し、解析関数の条件には使用しない。


入力は `../archive/tmp-test6-complete-upstream-to-ap.json`。

物理リンクと論理リンクは区別していない。自己ループは隣接解析から除外する。
削除ケースはメモリ上で作成し、入力は変更しない。

## 比較した仮説

1. 全端点（次数1）からの最短距離の局所極大。
   weak は隣接点の距離が自分以下、strict はすべて自分未満。
2. 端点間の全435組について、そのノードを途中に含む最短経路が存在するか。
   経路本数や媒介中心性ではなく、該当する端点ペアの数。
3. 全端点からの距離ベクトルの比較。
   全成分で同じか遠く、少なくとも一成分で遠い別ノードを dominator とする。
   これは「遠い方を優先した場合」の仮説で、上流の定義ではない。
4. 次数2ノードだけからなる連結成分を鎖状領域として抽出。
   領域の接続口同士の直結有無と、領域を除いたときの端点間距離変化を調べる。
   冗長領域全般を抽出するアルゴリズムではなく、限定した構造仮説。

## 結果

両ケースとも端点30台、全体は連結。

| 指標 | Internetあり | Internetなし |
|---|---|---|
| strict が全端点で成立 | Internetのみ | なし（ISP-A/Bは各28/30） |
| 端点間最短経路の途中に現れない非端点 | 24台 | 23台 |
| 距離ベクトルで他に支配されない非端点 | 16台 | 18台（ISP-A/Bは含まれない） |
| 次数2領域の接続口が2つあり、接続口間に直結がない | 5領域 | 6領域 |

Internet、ISP-A/B、先に残った3候補はいずれも端点間435組の最短経路の途中に
現れない。「端点間の通過点でない」だけでは区別できなかった。

### 周囲の構造の違い

`acx7024x.stage`、`cisco8711-48z.moip`、`fx2.5g` はそれぞれ別の
次数2ノードと対を形成し、同じ内部機器2台
`cisco8711-32fh.noc` と `ptx10002-36qdd.noc` を結ぶ。
その内部機器同士には直結もあるため、各対は3リンクの迂回路になる。
各対を除いても全435端点ペアの接続・最短距離は変わらない。

Internet の隣接先 ISP-A/B 同士には直結がない。
Internet 削除後の ISP-A の隣接先 mx301/cisco8712、
ISP-B の隣接先 mx301/ptx10002-60mr も、それぞれ直結はない。
ただし、これらの領域を個別に除いても全端点間距離は変わらない。

この局所構造の違いで先の3候補とISPは区別できるが、
`qfx5250-oe-l.dc`、`xh9320-64eo.dc`、`cx10000-1.dc`、`cx10000-2.dc`
も「接続口間に直結がない次数2領域」として残る。
従って、この条件も最上流検出として採用していない。

### 距離ベクトル

Internetありでは、Internet が先の3候補の距離ベクトルを支配する。
しかし Internetなしでは先の3候補が残り、ISP-A/Bはそれらに支配される。
単純に「全端点からより遠い」を選ぶ方法は期待するISP検出にならない。

## 結論・未検証

比較対象間の構造差は見つかったが、今回試した単独指標ではISP2台だけを
意味的な最上流として選べない。今回の入力に合わせた重み・閾値・条件の継ぎ足しはしない。
構造だけで検出不可能と証明したわけでもない。

全ノード集合の領域探索、同距離領域の縮約、一般の冗長ブロック分解は未実施。
領域削除は抽出した次数2成分ごとで、非隣接のISP-A/Bを同時削除する検査ではない。
重み付き経路、方向が保証されたリンク、物理・論理リンク別解析も未実施。
これらは別仮説として比較する必要があり、配置制約としては導入していない。

非連結グラフでは同じ連結成分の端点だけを使う。端点のない成分では
sources=0 を返し、「全端点で成立」を自明に上流判定してはいけない。
