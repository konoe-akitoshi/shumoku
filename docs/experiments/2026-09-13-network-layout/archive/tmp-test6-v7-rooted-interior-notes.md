# V7: Internet 起点の内部階層・配線評価

本体には未統合の実験。入力は従来と同じ 89 ノード・160 リンク・31 サブグラフ。
最新結果: `tmp-test6-v7-rooted-interior-refined.svg` と同名 `-report.json`。
前後の部分比較: `tmp-test6-v7-interior-comparison.png`。

## 変更

- ユーザー指定 `test:internet` から全リンクを無向 BFS。役割ラベルは配置に使わない。
- 内部階層もこの距離の順序を使う。「外部接続を持つから最上段」を廃止。
- 同じ距離は一行。グループ内に存在しない距離の空行は作らない。
- 複数の内部上流隣接ノードを `parentNodes` に保持。同距離リンク・冗長リンクも削除しない。
- 枠は行の実寸から算出。幅上限、折り返し、固定の段数は追加していない。
- 各グループの行内順列を列挙（今回合計 265 通り、最大 48 通り/グループ）。
- 内部線とノード→境界の線を、交差・無関係ノード貫通・直線の重なり・接続長で評価。
- 左右順と境界端点を 3 回まで交互更新し、外部配置の各候補を評価。最終候補は実際の外部経路で比較。
- 評価の規格化分母は変更前の Internet 起点図で固定。枠変更後の大きな初期余白やウォームスタート位置では変更しない。

## 結果（前の図 → 最新）

| 指標 | 前 | 最新 |
|---|---:|---:|
| 内部交差（境界への線を含む） | 98 | 22 |
| 内部線の無関係ノード貫通 | 73 | 43 |
| 内部線の同一直線上の重なり | 24 | 5 |
| 外部経路の交差リンク対 | 56 | 71 |
| 全接続の中心基準経路長合計 | 90659.08 | 83282.24 |

15 ノードの内部深さと 4 グループの内容由来サイズが変わった。
最終チェックでは階層逆転、ノード重なり、枠重なり、枠外ノード、外部経路の枠貫通はいずれも 0。
内部改善と全線長の短縮は確認できたが、外部交差は増加。すべての指標が改善したわけではない。

## 限界

これは表示上の階層であり、実際の通信経路やトラフィック方向の推定ではない。
深さは BFS で固定しており、階層自体の代替案は探索していない。
一行の同階層ノード間を直線で結ぶ条件では、重なりを避けられない接続もある。
全体最適性は保証しない。内部と外部の交差は別領域のイベントとして評価する。
