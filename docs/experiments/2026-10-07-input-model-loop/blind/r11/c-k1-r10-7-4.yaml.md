1. The two IPsec tunnels are represented as separate links in the VPN connection, but the format has no field to distinguish their identities or attributes.
2. I used conventional product paths for the Yamaha, Dell, Palo Alto, EC2, and RDS products; used `unknown` for the AP port because the format has no way to mark a port as unknown; and represented the internet gateway attachment through `sub-a` because no subnet was specified for it. I treated the cluster name `prod` as the host reference for `app-1`, and the VPC as a routing domain.
3. It is unclear whether an endpoint using `segment` is intended to describe a device’s attachment to that segment or a link to the segment as a shared network. The types say both that a node-to-segment link puts the node in the segment and that a link listing a segment carries it.
