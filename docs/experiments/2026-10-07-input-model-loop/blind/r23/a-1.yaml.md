1. ExpressRoute 回線の途中にある機器は不明なので、表現していません。
2. `hq`、`osaka` というグループ ID、ノードの type、Azure routing domain は補いました。ExpressRoute ゲートウェイへのリンクは、途中の機器が不明なため rt-1 と Azure routing domain の接続として表しました。WAN の契約帯域 300M はリンクの `description` に記しました。形式には契約帯域専用の項目がありません。
3. 接続先が明示されていない回線をどう表すかは少し曖昧です。ExpressRoute を Azure routing domain への接続として表しましたが、形式上、routing domain はネットワークのルーティング境界を意味するため、回線やクラウドサービスの接続先として使うのが適切かは判断しづらいです。
