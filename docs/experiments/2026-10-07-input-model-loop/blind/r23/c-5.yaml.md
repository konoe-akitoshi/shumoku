1. **表現できなかったこと:** ExpressRoute の途中の機器が分からないこと自体は、途中のリンクやノードを書かないことで表しました。LAG の2本が論理的に束ねられていることは connection で表しましたが、リンク集約の方式までは表せません。
2. **推測・追加したこと:** ノードの `type`、支店名を `group` にしたこと、各論理接続の ID とラベルは補いました。広域イーサネットの `speed: 300M` は契約帯域として記載しましたが、両端の引き渡し速度 1G はポート速度なのか別のリンク速度なのか判別できないため省略しました。ExpressRoute の `connection` は回線を表すものとして補いました。
3. **形式で不明だったこと:** `speed` がポート速度、リンク実速度、契約帯域のどれを表すのか不明です。特に広域イーサネットの 1G の引き渡し速度と 300M の契約帯域をどう併記するか分かりません。また、IPsec トンネルの両端ポートや帯域が不明な場合の表し方も明示されていません。
