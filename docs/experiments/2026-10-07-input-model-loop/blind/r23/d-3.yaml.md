```yaml
name: 本社と大阪支店のネットワーク

nodes:
  - id: rt-1
    type: router
  - id: sw-1
    type: switch
  - id: sw-2
    type: switch
  - id: prn-1
    type: printer
  - id: rt-2
    type: router
  - id: ergw
    type: expressroute-gateway

connections:
  - id: lag-1
    label: LAG
  - id: wan-1
    label: 広域イーサネット
  - id: expressroute-1
    label: ExpressRoute
  - id: ipsec-1
    label: バックアップ IPsec トンネル

links:
  - endpoints:
      - node: rt-1
        port: te1
      - node: sw-1
        port: te0/1
    speed: 10G

  - endpoints:
      - node: sw-1
        port: te0/47
      - node: sw-2
        port: te0/47
    speed: 10G
    connection: lag-1

  - endpoints:
      - node: sw-1
        port: te0/48
      - node: sw-2
        port: te0/48
    speed: 10G
    connection: lag-1

  - endpoints:
      - node: sw-2
        port: ge0/10
      - node: prn-1
    speed: 100M

  - endpoints:
      - node: rt-1
        port: ge0
      - node: rt-2
        port: ge0
    speed: 1G
    bandwidth: 300M
    connection: wan-1

  - endpoints:
      - node: rt-1
      - node: ergw
    bandwidth: 2G
    connection: expressroute-1

  - endpoints:
      - node: rt-2
      - node: rt-1
    virtual: true
    connection: ipsec-1
```

1. ExpressRoute の途中の機器や経路は分かりません。リンク形式では中間機器を表す必要がないので、両端を直接結ぶリンクとして表しました。
2. 「本社」「大阪支店」という場所はグループとして表せますが、どの機器がどの拠点にあるかが明示されていません。機器の種類（router、switch、printer、expressroute-gateway）、接続のラベル、接続 ID は YAML を組み立てるための推測・追加です。プリンタ側のポート名は不明なので省略しました。
3. LAG やバックアップトンネルのような論理接続を `connection` でまとめられることは分かりますが、回線帯域やリンクの `speed` を複数リンクからなる論理接続全体に付ける方法はありません。Tunnel は `virtual: true` としました。
