The CLI now carries the libraries released with core 0.6.0. It builds them into its own file, so CLI 0.3.0 still drew with core 0.5.0: no colour for a line's one VLAN, `external` and `cloud` nodes not always at the top, a VM on a host no line reaches left out, and the same network drawn differently when its links were listed in another order.
