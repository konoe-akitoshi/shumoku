2. I added a `vpn-1` node to represent the VPN connection, and modeled its endpoint links as virtual. I also treated the VPC, subnets, and internet gateway as nodes or link endpoints where needed to show attachments.
3. The format does not say how to represent routing-table membership or a network attachment when it is not a link. In particular, `Node.network` describes a node’s overall network, while the VPC and subnet attachment details are not directly represented. It is also unclear whether `type` and `product` should use canonical identifiers or display names.
