```yaml
groups:
  - id: hq
    label: 本社
  - id: osaka
    label: 大阪支店

connections:
  - id: lag-sw1-sw2
    label: LAG
  - id: wan-hq-osaka
    label: 広域イーサネット
  - id: expressroute
    label: ExpressRoute
  - id: backup-ipsec
    label: バックアップ IPsec

nodes:
  - id: rt-1
    type: router
    group: hq
  - id: sw-1
    type: switch
    group: hq
  - id: sw-2
    type: switch
    group: hq
  - id: prn-1
    type: printer
    group: hq
  - id: rt-2
    type: router
    group: osaka
  - id: ergw
    type: gateway

links:
  - endpoints:
      - node: rt-1
        port: te1
      - node: sw-1
        port: te0/1
    speed: 10G

  - endpoints:
      - node: sw-1
        port: te0/47
      - node: sw-2
        port: te0/47
    speed: 10G
    connection: lag-sw1-sw2

  - endpoints:
      - node: sw-1
        port: te0/48
      - node: sw-2
        port: te0/48
    speed: 10G
    connection: lag-sw1-sw2

  - endpoints:
      - node: sw-2
        port: ge0/10
      - node: prn-1
    speed: 100M

  - endpoints:
      - node: rt-1
        port: ge0
      - node: rt-2
        port: ge0
    speed: 300M
    cable: Ethernet
    connection: wan-hq-osaka

  - endpoints:
      - node: rt-1
      - node: ergw
    speed: 2G
    connection: expressroute
    assumed: true

  - endpoints:
      - node: rt-2
      - node: rt-1
    connection: backup-ipsec
    virtual: true
```

1. **表現できなかったこと:** 広域イーサネットの引き渡しが両端とも 1G であることと、プリンタのポートが 1G 対応であることは、リンクの稼働速度とは別の属性なので表せません。回線の途中にある機器が不明であることも、リンクの `assumed` は接続自体が未確認という意味なので、そのままでは表しにくいです。
2. **推測・追加したこと:** ノードの `type`（router / switch / printer / gateway）と、本社・大阪支店の `group` を追加しました。ExpressRoute の回線途中は不明ですが、接続自体は記述されているため、リンクを `assumed` にはしませんでした。ExpressRoute ゲートウェイと rt-1 の間を直結として記述したのは、途中の機器を特定できず、リンクの経路を表す欄もないためです。
3. **形式で不明瞭だったこと:** `Connection` が「複数のリンクでできた論理接続」とされていますが、広域イーサネットや ExpressRoute のように単一リンクとして表した接続にも付けてよいかが明記されていません。また、リンクに契約帯域とポートの対応速度を記録する欄がありません。
