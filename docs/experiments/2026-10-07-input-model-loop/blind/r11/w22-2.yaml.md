1. The format has no fields for cable length or cable medium/type, so those details are retained in link descriptions. The DAC link’s 10G rate is stated in its description but is not representable as `speed`, since `10G` was not explicitly stated as the link’s operating speed.
2. The description calls this a rack but does not explicitly say which devices are in it; I placed the named devices, including `sw-2` and `pdu-1`, in the rack. I inferred node types for the PDU and `sw-2` from their names/context.
3. It is unclear whether a power connection should be represented as an ordinary link, and whether port names for power inlets belong on the device endpoint. I recorded the inlet in the link description and the PDU outlet as its port.
