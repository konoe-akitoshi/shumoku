1. The format cannot express that db-1's address is unknown, or that mon-1 is known only from a monitoring system.
2. I added a `server-room` group and placed the known physical hosts, core, web-1, and db-1 there. The description implies a server room but does not explicitly assign each device to it. I also chose node `type` values for the switch, hosts, and VMs.
3. It is unclear whether `Node.assumed` is suitable for mon-1: the node is known to exist, but its placement and network are unknown. I left it unset because the description does not say the VM's existence is unconfirmed.
