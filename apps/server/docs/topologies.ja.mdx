## トポロジーの作成

1. サイドバーの **Topologies** をクリック
2. **Add Topology** をクリック
3. 名前を入力して保存
4. 開いた **Sources** 画面で、Manual ソースまたはプラグインのデータソースを追加

## 手で書く

Manual ソースの編集画面で、構成を YAML で書けます。YAML には構成（ノード・リンク・グループ・セグメントなど）だけを書きます。プラグインが見つけた識別情報や、図の位置・色などは YAML に出ず、そのまま保たれます。

```yaml
name: My Network
groups:
  - id: dc
    label: DC
nodes:
  - id: router1
    label: Core Router
    type: router
    product: juniper/mx204
    group: dc
  - id: switch1
    label: Distribution Switch
    type: l2-switch
    group: dc
links:
  - endpoints: [{ node: router1, port: ge-0/0/0 }, { node: switch1, port: ge-0/0/1 }]
    speed: 10G
```

- リンクは `endpoints` に両端を書きます。ポートが分からなければ省きます。
- 速度は `speed` に `1G`・`10G`・`2.5G` のように単位付きで書きます。
- グループは `groups` の中に入れ子で書き、ノードは `group` で属するグループを指します。
- 書いていないことは「無い」ではなく「分からない」として扱われます。

旧形式（`from` / `to`、`subgraphs`、`file:` によるファイル分割）は読めません。書き直してください。

## 図の描かれ方

図の上下は入力から決まります。座標や上下を書く欄はありません。

- 外側（インターネット・ISP・クラウドなど）は `type: external` または `type: cloud` のノードで書くと、そこが図の最上段になり、そこから先へ向かって下の段に並びます。名前をつけた境界がなければ、物理リンクと仮想リンク（`virtual: true`）の両方が付いているノードが境界とみなされます。どれもなければ、つながったまとまりごとに上流を推測します。種類（ルーター・ファイアウォール > L3 スイッチ > L2 スイッチ > AP の順）、次に一番速いリンク、それでも決まらなければつながりの中心のノードを最上段にします。これは簡易な推測なので、上下を正しく描きたいときは外側のノードを書いてください。
- 線は直角と 45 度だけで描かれます。矢印・スプライン・二重線は廃止されました。仮想リンクは破線、見込みのリンクは点線で描かれます。線の太さは `speed` から決まります。
- 入れ子のグループは枠で囲まれ、1 枚にまとめて描かれます。枠を別シートに分ける機能（`file:` / `pins`）は廃止されました。
- トポロジーの **Settings** > **Display** では **Hide Disconnected Nodes**（リンクのないノードを隠す）だけを切り替えられます。線の形式（エッジスタイル・スプライン）の設定は廃止されました。

## データソースの紐付け

トポロジーの **Settings** タブで:

1. **Metrics Source**（Zabbix または Prometheus）を追加 — リアルタイムのリンク使用率・ノード状態を取得
2. **Topology Source**（NetBox）を追加 — トポロジーデータの自動生成・マージ
3. **Node Mapping** を設定 — トポロジーのノードと監視対象ホストを関連付け

## 共有

トポロジーの **Share** ボタンをクリックすると公開リンクを生成できます。リンクを持つ誰でもログインなしでトポロジーを閲覧できます。

アクセスを取り消すには、トポロジー設定で共有トークンを削除します。

## エクスポート

トポロジービューアの **Export** から、図全体を SVG または 2 倍解像度の PNG
としてダウンロードできます。単体で動作するインタラクティブ HTML も出力できます。
Server のエクスポートは、ビューアおよび CLI と同じ描画エンジンとレンダラーを使用します。
階層シートは廃止され、入れ子のグループは 1 枚にまとめて描かれます。
