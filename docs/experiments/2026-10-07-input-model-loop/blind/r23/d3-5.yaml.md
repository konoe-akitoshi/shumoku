1. **表現できなかったこと:** ExpressRoute の途中に機器があることは分かっていますが、その機器や経路は特定できません。回線帯域 2G は ExpressRoute リンクに記載しましたが、書かれている帯域がリンクの実効速度なのか契約帯域なのかは型では区別できません。
2. **推測・補足したこと:** 本社と大阪支店を `group` として表し、機器種別を補いました。ExpressRoute の接続先を表すため `azure` という routing domain を追加しました。WAN と ExpressRoute の引き渡しでいう Ethernet は `cable` に記載し、ExpressRoute と IPsec のリンクは物理ケーブルのない仮想リンクとして表しました。
3. **不明瞭だったこと:** ExpressRoute ゲートウェイ `ergw` を Azure の routing domain にどう結びつけるべきかが型だけでは明確でありません。また、LAG のような論理接続と個々の物理リンクの関係は `connection` で表せますが、接続が LAG であることを明示する専用の属性はありません。
